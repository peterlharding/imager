# Imager 0.8.0

_Released 2026-07-27_

This release introduces app Settings, starting with a customizable image background.

## Highlights

- **Settings window (⌘,).**
  A new Settings window with an Appearance pane. It is organized into tabs so more settings can be
  added over time.
- **Custom image background.**
  Choose the background shown behind the image: a solid colour (preset swatches plus Red/Green/Blue
  sliders) or a checkerboard texture, with an opacity slider that blends the fill over the standard
  window background. A live preview shows the result.
- **App icon.**
  Imager now has an app icon.

## Notes

- Background choices are saved and apply across launches.
- Colour selection uses in-app controls rather than the system colour panel, avoiding a rendering
  issue with the colour wheel on current macOS.
