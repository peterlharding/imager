# Imager 0.5.1

_Released 2026-07-27_

A small follow-up to 0.5.0 that refines cropping.

## Changed

- **Image info reflects the cropped image.**
  After you crop, the info inspector now shows the cropped dimensions (and marks the image as
  edited) rather than the source file's original metadata.
- **Save As… moved to the File menu.**
  Saving a copy of the image is now File ▸ Save As… (⇧⌘S), matching the standard macOS convention
  (previously Image ▸ Export…). The original file is still never modified.
