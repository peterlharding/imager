# Imager 0.1.0

_Released 2026-07-26_

The first release of Imager - a native macOS app for working with images.
This version establishes the project scaffold and the core "open and view an image" flow.

## Highlights

- **Open images three ways.**
  Use File ▸ Open… (⌘O), the toolbar Open button, or drag an image file onto the window.
- **View at a glance.**
  The opened image is scaled to fit the window while preserving its aspect ratio, with high-quality interpolation.
- **Clear feedback.**
  A friendly empty state explains how to open an image, and an alert appears if a file can't be read as an image.

## Under the hood

- SwiftUI app targeting macOS 14.0 and later.
- App Sandbox enabled with read-only access to user-selected files.
- Project uses Xcode filesystem-synchronized groups, so new source files are picked up automatically.

## Known limitations

- View only - no zoom, pan, editing, or metadata display yet.
- Opens a single image at a time; no folder browsing or thumbnails.
