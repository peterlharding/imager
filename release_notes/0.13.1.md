# Imager 0.13.1

_Released 2026-07-29_

This is a packaging release.
The application is unchanged from 0.13.0, so everything in the
[0.13.0 notes](0.13.0.md) applies unaltered.

## Highlights

- **The first Imager release you can download and run.**
  Attached to this release is a signed, notarised, stapled build.
  macOS will open it without a Gatekeeper warning.

## Why 0.13.1 exists

0.13.0 was published before its build was attached, and releases on this repository are immutable.
An asset cannot be added to a release after it has been created, and deleting the release does not
help: the tag name stays reserved, so it cannot be recreated with the file included.
0.13.0 therefore remains a tag without a release page, and this version carries the download instead.

The release process has been corrected so the artifact is built, notarised, and verified *before*
the release is created, and attached in the same command.

## Verifying the download

The attached `Imager-0.13.1.zip` is signed with a Developer ID Application certificate and
notarised by Apple. To confirm that yourself after unzipping:

```sh
spctl --assess --type execute --verbose=2 Imager.app
```

Expect `accepted` and `source=Notarized Developer ID`.
