# Imager 0.18.0

_Released 2026-07-29_

This release adds tone and colour adjustments.

## Highlights

- **Adjust pane.**
  The inspector (⌘I) now has two panes, Info and Adjust, switched by a segmented control.
  Adjust holds exposure, highlights, shadows, contrast, saturation, vibrance and hue, with a
  Reset button.
- **Live.**
  The image updates as you drag a slider, not only when you let go.
- **One drag, one undo.**
  A whole drag is a single step in the edit history, so ⌘Z takes back the adjustment rather than
  the last few pixels of slider travel.
  Adjusting exposure and then contrast leaves two steps, so you can undo just the contrast.

## Under the hood

- Adjustments join the same edit history as crop, rotate and flip, so they work with undo and
  redo, count as unsaved work, and are included when you save or export a copy.
- Values are absolute, so a later adjustment replaces an earlier one rather than stacking on it.
  A long editing session still costs a single filter pass, however many times the sliders have
  been moved.
- Rendering runs through Core Image in a linear colour space, which is what keeps exposure
  changes from going wrong in the midtones.

## Notes

- Adjustments apply to the image as loaded.
  For a camera RAW file that is the demosaiced rendering macOS produces, not the sensor data, so
  pushing exposure will not recover blown highlights the way a RAW developer does.
- A large exposure push on an 8-bit file can show banding in smooth gradients.
  That is the source, not the rendering: the same push measured identically at 8-bit and 16-bit
  precision, because output precision cannot recover levels the file never held.
- `data/adjustment-test.png` in the repository is a six-band pattern for exercising all of this.
