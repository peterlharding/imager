# Imager 1.0.0

_Released 2026-07-30_

Imager is a native macOS image viewer and light editor.
This is its first stable release: the application is the same as 0.22.0, and the version marks the
point at which it is finished enough to rely on.

## What it does

**Opens almost anything.**
Around sixty formats, inherited from macOS itself: PNG, JPEG, TIFF, HEIC, GIF, BMP, WebP, PSD, and
camera RAW from Nikon, Canon, Sony, Fujifilm, Olympus, Panasonic, Pentax, Leica and others.
Open a file, drop one on the icon, right-click a folder and choose Open in Imager, or point the
`open` command at it.

**Browses a folder as a set.**
A thumbnail sidebar, arrow-key navigation, and ordering by name, date or size.
Move to Trash (⌘⌫) steps straight on to the next image, so a shoot can be culled quickly, and a
full-screen slideshow runs the folder at whatever interval suits.

**Tells you what is in the file.**
Name, location, dimensions, colour model, bit depth and profile, plus the camera, EXIF and GPS
metadata the file carries.

**Edits without touching the original.**
Crop, rotate, flip, and adjust exposure, highlights, shadows, contrast, saturation, vibrance and
hue.
Multi-step undo and redo, and Revert to Original when you would rather start again.
Imager never writes to the file you opened: Save As and Export As write a copy, in PNG, JPEG, GIF,
TIFF or HEIC.

**Develops camera RAW from the sensor data.**
Exposure, white balance as temperature and tint, boost and shadow boost, and highlight recovery
where the camera and system support it.
These act before the image is rendered, which is what makes proper white balance and highlight
recovery possible at all.

**Repeats work across a shoot.**
Save what you did to one image as a recipe, apply it to another, or run it over a whole folder.
Recipes carry RAW development, so developing one frame and applying it to the rest works.
Batch processing never writes over an original and refuses to write into the folder it is reading.

**Hands off to whatever else you use.**
Edit With opens the current file in GIMP, darktable, the DxO suite, an upscaler, or anything else
installed — Imager needs no knowledge of the tool.

## Deliberate choices

Some behaviour is the way it is on purpose, and is worth knowing:

- **Your files are not modified.** Editing happens in memory; saving writes a copy.
- **Batch never overwrites.** A name already taken becomes `photo-01.png`, and the folder being
  processed cannot be the destination.
- **Move to Trash does not ask.** The Trash is itself the undo, and a prompt on every image would
  defeat the point of culling.
- **Crops are left out of recipes.** A crop belongs to one image's dimensions; it is tone that is
  worth reusing.
- **Reset Development returns to your camera's reading**, not to zero, because a RAW file has no
  fixed neutral.
- **Unsaved edits are never discarded silently.** Closing, opening something else, or quitting will
  ask first.

## Requirements

macOS 26 or later.
The build targets macOS 14.0 and calls no unavailable API, so it may well run on earlier systems —
it simply has not been tried on one yet.

## From here

The recipe file format, the preference keys and the behaviour described in the README are now
treated as things not to break without a major version.
Recipes carry a format version and are read tolerantly, so one saved today will still load after
further adjustments are added.
