# Imager 0.7.0

_Released 2026-07-27_

This release adds a custom About window.

## Highlights

- **Custom About window.**
  Apple menu ▸ About Imager now opens a custom panel showing the app icon, name, version and build
  number, a short description, and the copyright.

## Notes

- The window opens from the menu even when no image window is open, and does not block the app.
