# Imager 0.10.0

_Released 2026-07-27_

This release adds Finder integration.

## Highlights

- **Open With.**
  Imager now registers as a viewer for images and folders, so it appears in Finder's
  right-click "Open With" menu.
- **Double-click and drag-to-icon.**
  Double-clicking an image can open it in Imager, and files or folders dropped on the Imager icon
  open in the app.

## Notes

- Imager registers as an alternate opener, so it does not take over the default handler for images.
- macOS may take a moment to refresh the "Open With" list the first time.
