# Imager 0.15.0

_Released 2026-07-29_

This release adds copy and paste, and fixes saving a copy of a camera RAW file.

## Highlights

- **Copy and paste.**
  ⌘C puts the image on screen on the clipboard, edits and all, and ⌘V opens an image from it.
  A pasted image has no file behind it, so Imager treats it as unsaved from the moment it
  appears: closing, opening something else, or quitting will ask before discarding it.
  Export As settles it.

## Fixed

- **Save As works on camera RAW.**
  Imager can open RAW files from Nikon, Canon, Sony, Adobe and others, but Save As took the
  output format from the source file and asked macOS to write RAW, which is impossible.
  It failed every time with "Couldn't create a Nikon raw image file".
  Save As now falls back to PNG when the source format cannot be written.
  Formats that can be written are unaffected and keep their own format and extension.

## What Imager can read and write

Reading is broad and inherited from macOS: around 60 formats, including PNG, JPEG, TIFF, HEIC,
GIF, BMP, WebP, PSD, and camera RAW from most manufacturers.
RAW files open, browse and show their EXIF metadata like anything else.

Writing is a much shorter list, and **no RAW format can be written** by any application: RAW
records what a sensor captured, and nothing re-encodes to it.
Export As offers PNG, JPEG, GIF, TIFF and HEIC.

This is now written up in the README.
