# Imager 0.6.1

_Released 2026-07-27_

A small enhancement for finding the current image on disk.

## Added

- **Location in Info.**
  The image info inspector now shows a "Where" row with the containing folder path
  (home abbreviated to `~`), alongside the file name.
- **Show in Finder.**
  File ▸ Show in Finder (⇧⌘R) reveals the current image in Finder. Also a button at the bottom of
  the info panel.
- **Copy Path.**
  File ▸ Copy Path (⌥⌘C) copies the full file path to the clipboard. Also a button in the info panel.
