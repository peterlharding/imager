# Imager 0.17.0

_Released 2026-07-29_

This release lets Imager hand an image to whatever tool you want to edit it in.

## Highlights

- **Edit With.**
  File ▸ Edit With opens the image you are looking at in another application: GIMP, darktable,
  the DxO suite, an AI upscaler, a denoiser, or anything else you have installed.
  Imager knows nothing about any of them, so a tool installed later appears on its own.

## How the list is put together

Applications that declare themselves editors of the file type are listed first.
Everything else that can open the file sits under **All Applications**, and **Other…** picks any
application at all.

The split is a hint rather than a rule, and the second group is deliberately kept rather than
hidden.
darktable, for one, declares itself a *viewer* of every image type despite being an editor, so
filtering strictly to declared editors would hide exactly the tools this was built for.

## Notes

- Edit With opens the file as saved on disk.
  Unsaved crops or rotations are not carried across, so save a copy first if you want them.
- The menu is unavailable when there is no file to hand over, including for a pasted image,
  which has nothing on disk behind it.
