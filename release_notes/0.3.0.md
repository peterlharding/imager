# Imager 0.3.0

_Released 2026-07-26_

This release adds folder browsing with a thumbnail sidebar.

## Highlights

- **Open a folder of images.**
  File ▸ Open Folder… (⇧⌘O), or drag a folder onto the window. Imager lists the folder's images
  (immediate folder only) in a thumbnail sidebar.
- **Thumbnail sidebar.**
  QuickLook-generated thumbnails, sorted Finder-style by name, with non-image files filtered out.
  Click a thumbnail to view that image.
- **Navigate quickly.**
  Move between images with ← / → (also View ▸ Previous/Next Image), or ↑ / ↓ in the sidebar.
- **Toggle the sidebar.**
  Hide or show the thumbnails from the toolbar or View ▸ Show/Hide Thumbnails (⌥⌘S).

## Notes

- Because the app is sandboxed, opening a single image file shows just that image; open the
  containing folder to browse all of its images. Opening a folder grants access to its contents.

## Under the hood

- New QuickLook-backed thumbnail cache (`ThumbnailProvider`).
- The image model gained folder state and navigation; the main view uses a split view with the
  thumbnail sidebar when a folder is loaded.
