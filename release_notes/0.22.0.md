# Imager 0.22.0

_Released 2026-07-30_

This release develops camera RAW files from their sensor data.

## Highlights

- **Develop RAW.**
  Open a RAW file and the Adjust pane gains a Develop RAW section: exposure, white balance as
  temperature and tint, boost and shadow boost, and highlight recovery where your camera and system
  support it.
- **These are not the same sliders as below them.**
  They act on the sensor data before the image is rendered, which is what makes proper white balance
  and highlight recovery possible.
  The adjustments underneath still act on the rendered result, and the two work together.
- **Reset returns to your camera's reading.**
  A RAW file has no fixed neutral: it opens with whatever the decoder made of the shot, and that is
  what Reset Development goes back to, rather than zero.
- **Develop one frame, apply it to the shoot.**
  Recipes carry RAW development, and Process Folder applies it across a whole folder.
  A recipe made from a RAW applied to an ordinary image simply ignores the development and applies
  the rest.

## Notes

- Dragging a Develop slider works on a reduced-size render for speed and produces the full-size
  result when you let go. On a 36 megapixel file that is the difference between about 7 milliseconds
  a step and about 160.
- Highlight recovery requires macOS 26. Below that it is not offered, in the same way it is not
  offered for a camera whose decoder does not support it.
- Developing counts as unsaved work, and undoes, redoes and groups per drag like any other change.
- Saving a recipe from a RAW you have not developed records no development, so it will not pin
  other shots to this one's white balance.

## Under the hood

- The decoder is held open for as long as the file is: a fresh one per render costs 370-560 ms on a
  36 megapixel file and never less than 86 ms at any size, because that floor is the decode itself.
- The test suite is up to 204 tests across 17 suites, including tests that run against a real RAW
  file when one is present.
