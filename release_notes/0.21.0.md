# Imager 0.21.0

_Released 2026-07-30_

This release adds batch processing: do it once, then do it to the whole folder.

## Highlights

- **Process Folder.**
  File ▸ Process Folder… applies a saved recipe, or the changes you have made to the image on
  screen, to every image in the folder you are browsing.
- **Choose the output format.**
  Each image keeps its own format, falling back to PNG for camera RAW, or convert everything to
  PNG, JPEG, GIF, TIFF or HEIC.
- **Watch it, and stop it.**
  Progress is shown file by file, and Cancel stops after the image being worked on.

## Your originals are safe

Two rules, both deliberate:

- **Nothing is ever written over.**
  If a name is already taken the result becomes `photo-01.png`, then `photo-02.png`, and so on.
  Run the same batch twice and you get a second set, not a replaced one.
- **The folder being processed cannot be the destination.**
  Imager refuses it and asks for another, so the files being read are out of reach of the files
  being written.

A file that cannot be read or written is listed in a summary at the end rather than stopping the
run, so one awkward image does not cost you the other thirty-nine.

## Notes

- The source is the folder currently open, in the order shown, so sorting the folder first sorts
  the work.
- Processing runs one image at a time. That keeps memory steady on a folder of large RAW files, and
  the disk is the limit in any case.
- The test suite is up to 179 tests across 16 suites.
