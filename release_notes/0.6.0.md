# Imager 0.6.0

_Released 2026-07-27_

This release adds multi-format export and smarter Save As.

## Highlights

- **Export As.**
  File ▸ Export As lets you save a copy of the current image as PNG, JPEG, GIF, TIFF, or HEIC.
- **Save As preserves the format.**
  File ▸ Save As… (⇧⌘S) now defaults to the source image's own format instead of always PNG.

## Notes

- The original file is never modified; both commands write a new file you choose.
- Lossy formats (JPEG, HEIC) are saved at high quality.

## Under the hood

- Exporting now uses ImageIO (`CGImageDestination`), which enables formats such as HEIC and GIF
  that the previous bitmap-based writer could not produce.
