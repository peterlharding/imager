# Imager 0.2.0

_Released 2026-07-26_

This release adds image metadata, a recent-files list, and fixes a window-lifecycle bug.

## Highlights

- **Image info inspector.**
  A trailing panel shows file, image, camera (EXIF), and location (GPS) details for the current
  image. Toggle it with the toolbar button or View ▸ Show Image Info (⌘I). Values are selectable.
- **Recent files.**
  File ▸ Open Recent lists recently opened images and reopens them, remembering access across
  launches via security-scoped bookmarks. Includes a Clear Menu item.
- **Open from Finder.**
  Open images with "Open With… ▸ Imager" or the `open` command; those files are added to recents.

## Fixed

- Opening an image after closing the window now reliably brings a window back to display it.
  The app now uses a single-window scene, stays running when the window is closed, and reopens when
  its Dock icon is clicked.

## Under the hood

- Added `com.apple.security.files.user-selected.read-only` and
  `com.apple.security.files.bookmarks.app-scoped` entitlements to support persistent recent-file
  access within the sandbox.
