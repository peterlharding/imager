# Imager 0.12.0

_Released 2026-07-28_

This is a documentation-only release.
The application is unchanged from 0.11.0.

## Highlights

- **A real README.**
  The project README was a two-line stub.
  It now covers what Imager is, what it needs, how to build it, and what it can do.
- **Keyboard shortcut reference.**
  Every shortcut the app defines is listed in one table, from ⌘O through ⌘L and ⌘R.
- **Sandboxing and privacy, written down.**
  What access Imager asks for and why, including why opening a folder enables browsing while
  opening a single file does not.

## Notes

- No application code changed, so the 0.12.0 build behaves identically to 0.11.0.
- The feature and shortcut lists were checked against the source rather than written from memory,
  which corrected two claims that would have been wrong: the toolbar's zoom percentage is a button
  that returns to fit, not an editable field, and the info inspector reports colour model, bit
  depth, and colour profile rather than a single "colour space" value.
