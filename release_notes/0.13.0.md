# Imager 0.13.0

_Released 2026-07-29_

This release adds a slideshow, and puts the project's first automated tests in place.

## Highlights

- **Slideshow.**
  Open a folder and run it as a slideshow with View ▸ Start Slideshow (⇧⌘F) or the toolbar's
  play button.
  It goes full screen, hides the sidebar and inspector, and holds off display sleep while running.
- **It gives the window back.**
  Escape, or leaving full screen by any route, ends the show and restores the sidebar and
  inspector exactly as you had them.
- **It won't walk away from your work.**
  Editing the image on screen stops the show rather than advancing, so a running slideshow can
  never discard an unsaved crop or rotation.
- **Configurable.**
  Settings ▸ General sets the interval, from 1 to 60 seconds, and whether the show repeats
  continuously or stops after the last image.

## Under the hood

- Imager now has a test suite: 50 tests across 5 suites, run with ⌘U or `xcodebuild test`.
  They cover the pixel transforms, the unsaved-edit state machine, the slideshow rules, the
  recent-files limit, and the export format table.
- The Xcode scheme is now shared rather than living in local user data, so the tests run from a
  fresh clone.

## Notes

- A slideshow needs a folder. The command and the toolbar button stay hidden or disabled for a
  single image, since a slideshow of one is not a slideshow.
- The slideshow advances on its own timer rather than through the standard Next Image command,
  so it can wrap around at the end. Next and Previous still stop at the ends as before.
