# Imager 0.16.0

_Released 2026-07-29_

This release adds a Finder service, so folders can be opened in Imager from the right-click menu.

## Highlights

- **Open in Imager.**
  Right-click a folder or an image in Finder and look under **Services**.
  It browses a folder or opens an image, the same as any other way in.

## Why a service

Finder shows no "Open With" submenu for folders, no matter what an app declares.
Imager has registered as a folder viewer since 0.10.0, which is what makes dragging a folder onto
its icon and `open -a Imager <folder>` work, but that association can never produce a right-click
entry for a folder.
A Service can, so that is what this uses.

## Notes

- To give the service a keyboard shortcut, or to make it more prominent, use
  System Settings ▸ Keyboard ▸ Keyboard Shortcuts ▸ Services.
- macOS caches the list of available services.
  A newly installed copy may not appear in the menu until it has been launched once, or until you
  log out and back in.
