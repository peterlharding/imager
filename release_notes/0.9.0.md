# Imager 0.9.0

_Released 2026-07-27_

This release adds rotating, flipping, and a full-screen view.

## Highlights

- **Rotate and flip.**
  Rotate Left / Right (⌘L / ⌘R), Rotate 180°, and Flip Horizontal / Vertical, from the Image menu
  or the toolbar's Rotate popover.
- **Fine rotation.**
  A degree stepper with left/right nudge buttons for small-angle straightening.
- **Full screen.**
  A toolbar button (and the standard View ▸ Enter Full Screen) to view images full screen.

## Notes

- Rotating and flipping are non-destructive: Revert to Original restores the image, and Save As /
  Export saves the transformed result. The original file is never modified.
- Right-angle rotations are pixel-exact; fine-angle rotations expand the canvas to fit, leaving
  transparent corners (preserved when exporting to PNG or HEIC).
