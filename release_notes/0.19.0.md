# Imager 0.19.0

_Released 2026-07-30_

Housekeeping for working through a folder of images.

## Highlights

- **Move to Trash.**
  File ▸ Move to Trash (⌘⌫) sends the file you are looking at to the Trash and moves straight on
  to the next image in the folder, so a set can be culled quickly.
  Trashing the last image in a folder falls back to the one before it, and trashing the last
  remaining image returns to the empty state.

  It does not ask first.
  The Trash is itself the undo, Finder's ⌘⌫ does not prompt either, and a confirmation on every
  image would defeat the point of culling.

## Fixed

- **Save As says what it will write.**
  The menu item now reads "Save As PNG…" when the file's own format cannot be written, and plain
  "Save As…" otherwise.
  Falling back to PNG for camera RAW arrived in 0.15.0, but the menu item still read "Save As…",
  so the command changed format without saying so.

## Notes

- Move to Trash is unavailable for a pasted image, which has no file on disk behind it.
- It does not ask about unsaved edits, since the file those edits apply to is being thrown away.
