# Imager 0.14.0

_Released 2026-07-29_

This release adds a proper edit history and gives folder browsing an order you can choose.

## Highlights

- **Undo and redo.**
  ⌘Z and ⇧⌘Z step back and forth through your edits one at a time, across crop, rotate, and flip.
  The menu names the step, so you can see whether you are about to undo a crop or a rotation.
  Revert to Original still discards everything at once when that is what you want.
- **Sort a folder your way.**
  View ▸ Sort Images By orders a folder by name, date modified, or file size, and can reverse any
  of them.
  Name order is natural, so `photo2` comes before `photo10`.
  Changing the order keeps the image you are looking at on screen, and the choice is remembered.

## Fixed

- The image is no longer left oversized and pushed off to one side after a slideshow ends.
  A fitted image now re-fits whenever the window changes size.
- The same displacement when starting a slideshow from a small window on a large external
  display is fixed.
  The re-fit now responds to the resize itself rather than waiting for a layout pass, which a
  window resize does not reliably trigger.

## Under the hood

- Edits are recorded as a replayable list of operations rather than by copying the image at each
  step, so a long undo history costs almost nothing in memory.
- Whether there are unsaved edits is now derived from that history rather than being latched on.
  Undoing back to the last state you saved clears it; redoing away from that state sets it again.
- The test suite is up to 81 tests across 8 suites.

## Notes

- A deliberate zoom is preserved when the window resizes.
  Only an image that was fitted to the window gets re-fitted.
- Undo history belongs to the image on screen and starts fresh when you open another one.
