# Imager 0.5.0

_Released 2026-07-27_

This release adds selecting a region of an image and cropping to it, plus exporting the result.

## Highlights

- **Select and crop.**
  Switch to the Select tool (Pan/Select toggle in the toolbar), drag to draw a crop rectangle -
  move it by dragging inside, resize it with the handles - then Crop to Selection (⌘K).
- **Non-destructive.**
  Cropping changes only what's shown; Revert to Original brings the full image back at any time.
  The source file on disk is never modified.
- **Export.**
  Export… (⇧⌘E) saves the current (possibly cropped) image to a new PNG, JPEG, or TIFF file
  that you choose.

## Notes

- The new Image menu holds Crop to Selection, Revert to Original, and Export….
- After cropping, the image info inspector still reflects the original source file's metadata.

## Under the hood

- The crop selection is drawn and edited in image pixel coordinates, so it is independent of the
  current zoom.
- Export writes via a save panel, which grants the sandboxed app write access to the chosen file.
