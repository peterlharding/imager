# Imager 0.11.0

_Released 2026-07-28_

This release stops unsaved edits from being lost, and tightens the app's sandbox.

## Highlights

- **Nothing is discarded silently.**
  If an image has edits that haven't been written out, Imager asks before letting them go -
  when you open another image or folder, close the image, move to another image in a folder,
  or quit the app.
- **Saving is tracked.**
  Save As and Export now tell a completed save apart from a cancelled one, so cancelling the
  save panel no longer leaves the app thinking your edits are safe.
- **Clearer edit state.**
  The Info pane's State line reads "Edited (unsaved)" until you save a copy, then
  "Edited (copy saved)".

## Under the hood

- Sandbox entitlements were narrowed to what the app actually uses.
  User-selected file access is now read-write, which saving a copy requires; Downloads and
  Pictures folder access, camera, Bluetooth, location, printing, and USB have been switched off.

## Notes

- Saving a copy does not change the edit itself: Revert to Original stays available after a save,
  and the source file is still never modified.
- The confirmation is driven from app state rather than a nested `NSAlert`, because an alert
  opened from inside a menu action is torn down when the menu's tracking loop unwinds - which
  dismissed the prompt on its own and let the edits go.
